# 洛书 · Luoshu Bot

**一个可爱、略显内向的 QQ 群聊机器人**

基于 [NoneBot2](https://nonebot.dev) + OneBot v11 ｜ 本地大模型驱动 ｜ 数据不出本机

</div>

---

## 这是什么

洛书是一个住在 QQ 群里的小女孩 —— 说话轻声细语，被夸会害羞，喜欢听人讲心事。
她和群里每个人都是**平等的朋友**，谁都可以喊她的名字和她聊天。

```
洛书 讲个笑话
洛书 今天心情不太好，陪我说说话
```

如果说话的人恰好是她「偷偷喜欢」的那一位，她会藏不住地更在意一点、更害羞一点。

**开箱即用**：本地大模型驱动，不依赖任何付费接口，聊天数据不出本机。

## 安装

### 前置条件

| 项目 | 要求 |
| --- | --- |
| Python | **3.10 或更高** |
| [Ollama](https://ollama.com) | 最新版（提供本地大模型服务） |
| 登录端 | 任意 [OneBot v11](https://onebot.dev) 实现，通过 ws-reverse 连入 |

> 登录端（负责让机器人登入 QQ）不包含在本仓库内，请自行准备，并让它连接到
> `ws://127.0.0.1:8080/onebot/v11/ws`。

### 1. 拉取模型

```bash
ollama pull qwen2.5:7b
```

### 2. Windows

```text
1. 双击「安装依赖.bat」   （首次，创建虚拟环境并安装依赖）
2. 双击「启动bot.bat」
```

### 3. Linux

```bash
./install.sh             # 首次，创建虚拟环境并安装依赖
./start.sh               # 启动
```

想开机自启 / 崩溃自动重启，参考仓库内的 `luoshu.service.example`（systemd 模板）。

启动成功会看到：

```
[SUCCESS] nonebot | Succeeded to load plugin "ai_chat"
```

## 配置

所有配置集中在 `.env`（从 `.env.example` 复制一份，等号两边不要加空格，JSON 数组用双引号）。

### 最常改的两项

```ini
# 管理员 QQ（可多个）—— 谁拥有管理权限
SUPERUSERS=["100000000"]

# 洛书「偷偷喜欢的人」的称呼（可多个，逗号分隔）
CRUSH_NAMES=小美
```

**想让洛书「喜欢」别人？** 改上面两行就行，不用碰代码：

```ini
SUPERUSERS=["他的QQ号"]
CRUSH_NAMES=他的名字
```

### 其余常用项

```ini
NICKNAME=["洛书", "洛"]          # 机器人昵称
CALL_NAMES=洛书,洛洛,小洛,洛      # 喊名字唤醒用的称呼
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5:7b          # 使用的模型
AI_MAX_HISTORY=20                # 记住多少轮对话
AI_AT_SENDER=false               # AI 回复是否 @ 对方
GREETING_ENABLED=true            # 是否开启定时问好
```

改完保存，**重启机器人**生效。

### 模型怎么选（按显存从低到高）

| 模型 | 显存 | 说明 |
| --- | --- | --- |
| `qwen2.5:3b` | 约 2 GB | 快，效果一般，老机器 / 纯 CPU 可用 |
| `qwen2.5:7b` | 约 5 GB | **推荐**，日常够用 |
| `qwen2.5:14b` | 约 10 GB | 效果更好 |
| `qwen2.5:32b` | 约 20 GB | 最好，需要好显卡 |

> 完整配置项、维护方法和常见问题见 [`使用说明.txt`](使用说明.txt)。

## 功能

### 💬 AI 对话（所有人）
`@洛书 <内容>` 或 `洛书 <内容>` 直接开聊，带上下文记忆。
另有 `/人设`、`/切换`、`/reset`、`/history`。

### 🎲 娱乐
`/抽签`、`/运势`、`/塔罗`（可加"三张"）。

### 💗 心动专属
仅「她喜欢的那个人」可用：喊名字、被夸、早晚问安、`/心事`。

`/help`、`/h` 或 `@洛书 功能清单` 可随时查看完整功能表。

### 🛠 管理
`/统计`（日/周/月）、`/关键词`、`/禁言`、`whoami`；
管理员另有 `/model`、`/stat`、`/say`。

### ✨ 自动
新人进群欢迎、退群提示、戳一戳回应、每日定时问好、掉线私聊告警。

## 技术特性

- **本地大模型**：AI 对话走 Ollama，不依赖付费接口，**聊天数据不出本机**
- **四级权限**：管理员 > 群主 > 群管理员 > 普通成员，越权直接拦截
- **多群隔离**：关键词、统计数据按群独立存放
- **内容安全**：敏感词库过滤 AI 的输入与输出
- **跨平台**：Windows / Linux 均可

代码规模：14 个插件模块，约 2400 行。
