# 洛书 · Luoshu Bot

**一个可爱、略显内向的 QQ 群聊机器人**

基于 [NoneBot2](https://nonebot.dev) + OneBot v11 ｜ 本地大模型驱动 ｜ 数据不出本机

## 她是谁

洛书是一个住在 QQ 群里的小女孩 —— 说话轻声细语，被夸会害羞，喜欢听人讲心事。
她和群里每个人都是**平等的朋友**，谁都可以喊她的名字和她聊天。

> 嗯……你好呀，我是洛书。（有点小声）

不用 @ 也能唤醒，直接喊名字就行：

```
洛书 讲个笑话
洛书 今天心情不太好，陪我说说话
```

如果说话的人恰好是她「偷偷喜欢」的那一位，她会藏不住地更在意一点、更害羞一点 —— 但嘴上绝不会承认。

## 技术特性

- **本地大模型**：AI 对话走 [Ollama](https://ollama.com)（默认 `qwen2.5:7b`），不依赖任何付费接口，**聊天数据不出本机**
- **四级权限**：管理员 > 群主 > 群管理员 > 普通成员，越权直接拦截
- **多群隔离**：关键词、统计数据按群独立存放，互不干扰
- **防刷屏**：内置指令冷却
- **内容安全**：敏感词库过滤 AI 的输入与输出
- **跨平台**：Windows / Linux 均可，自带 `install.sh` / `start.sh` 与 systemd 模板

代码规模：14 个插件模块，约 2400 行。

## 快速开始

### 前置条件

| 项目 | 要求 |
| --- | --- |
| Python | **3.10 或更高** |
| Ollama | 最新版（提供本地大模型服务） |
| 登录端 | 任意 [OneBot v11](https://onebot.dev) 实现，通过 ws-reverse 连入 |

> 登录端（负责让机器人登入 QQ）不包含在本仓库内，请自行准备，并让其连接到 `ws://127.0.0.1:8080/onebot/v11/ws`。

### Windows

```text
1. 双击「安装依赖.bat」   （首次，创建虚拟环境并安装依赖）
2. 启动 Ollama            （一般开机自启）
3. 双击「启动bot.bat」
```

看到 `[SUCCESS] nonebot | Succeeded to load plugin "ai_chat"` 即成功。

### Linux

```bash
cp .env.example .env     # 按需修改配置
./install.sh             # 首次，创建虚拟环境并安装依赖
./start.sh               # 启动
```

想开机自启 / 崩溃自动重启，可参考仓库内的 `luoshu.service.example`（systemd 模板）。

## 配置

所有配置集中在 `.env`（等号两边不要加空格，JSON 数组用双引号）：

```ini
# 管理员 QQ（可多个）
SUPERUSERS=["100000000"]

# 洛书「偷偷喜欢的人」的称呼（可多个，逗号分隔）
CRUSH_NAMES=小美

# 机器人昵称与唤醒词
NICKNAME=["洛书", "洛"]
CALL_NAMES=洛书,洛洛,小洛,洛

# 本地大模型
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5:7b

# AI 记住多少轮对话
AI_MAX_HISTORY=20
```

**想让洛书「喜欢」别人？** 改两行就行，不用碰代码：

```ini
SUPERUSERS=["他的QQ号"]
CRUSH_NAMES=他的名字
```

重启后生效。完整配置项与常见问题见 [`使用说明.txt`](使用说明.txt)。

### 模型建议（按显存从低到高）

| 模型 | 显存 | 说明 |
| --- | --- | --- |
| `qwen2.5:3b` | 约 2 GB | 快，效果一般，老机器 / 纯 CPU 可用 |
| `qwen2.5:7b` | 约 5 GB | 推荐，日常够用 |
| `qwen2.5:14b` | 约 10 GB | 效果更好 |
| `qwen2.5:32b` | 约 20 GB | 最好，需要好显卡 |
