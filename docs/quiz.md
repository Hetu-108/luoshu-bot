# 督师科普答题

人工提供题目、正确答案和解析，程序按固定规则判分。Ollama 停机不影响答题。
新增「督师」人格，可配置 `AI_DEFAULT_PERSONA=督师`；切换人格不影响活动。

## 初始配置

`SUPERUSERS` 配置机器人管理员；群管理员只能通过 `/功能 关闭 答题` 管理本群开关。
新安装活动默认关闭、目标群为空。管理员私聊：

```text
/答题设置 {"groups":["群号1","群号2"],"start_date":"2026-11-01","end_date":"2026-11-30"}
/答题设置 开启 活动
```

上面的群号和日期是占位示例，须换成实际值。默认北京时间每天20:00发题，次日20:00截止；
每题单选2~6项，正确1分、错误0分、迟交不受理、首次提交有效、截止后才展示成绩。
同题多群共享每人的一次作答。群内排行仅统计该群已验证成员的作答；同分按答对数、首次提交时间排序。
群成员身份必须能通过登录端 `get_group_member_info` 验证；未加好友时能否私聊取决于 QQ 和登录端权限。

可设置 `publish_time`、`timezone`、`points`、`close_mode`（`next_day` / `same_day`）、
`late_ratio`（0~1，默认0）、`immediate_result`、`leaderboard_public` 和 `reminder_minutes`（默认0关闭）。
`same_day` 截止时间为当日23:59:59。设置排期规则只影响新录题；已录题用 `/改题` 调整。
结束日期当天仍可发题，已发布题目在自己的截止时间结算。关闭活动会暂停自动处理，重新开启后补处理。

## 录题与发布

管理员私聊 `/出题`，依次输入题干、图片或「跳过」、每行一个选项、答案、人工解析或「跳过」、发布日期。
支持「上一步」「取消」，会话30分钟无操作后过期；未保存草稿不跨重启。

| 命令 | 用法 |
|---|---|
| `/题库` | 按排期列出题目 |
| `/预览 Q0001` | 私聊预览，包含答案与解析 |
| `/改题 Q0001 分值 2` | 也支持 `题干 / 选项 / 答案 / 解析 / 日期 / 截止 / 图片` |
| `/改题 Q0001 {"title":"新题干"}` | JSON 修改多个字段 |
| `/删题 Q0001` | 60秒内再发 `/删题 Q0001 确认` |
| `/发题 [Q0001]` | 立即发题；不指定题号时须唯一可发题 |
| `/答案 [Q0001]` | 立即结算并公布，提前公布也会立即终止原截止时间 |
| `/答题总览` | 发题状态、人数、管理员可见正确数、待同步和告警 |

只有 `/发题` 和 `/答案` 允许在群里执行，仍要求 `SUPERUSERS`。
已发或发送结果不明的题目锁定编辑和删除，避免题干、答案与群内版本不一致。
图片下载并校验后按内容哈希保存在 `data/quiz/images/`，发布使用本地图片。
仅支持公共HTTP(S)图片地址，拒绝内网地址与重定向到内网，单张至多8MB。
题干、选项、解析经过已有敏感词过滤。

每天30秒扫描一次排期，重启后在截止前补发；已经过期的未发题不会作为新题发出，并通知管理员。
同题多群并发提交给登录端，QQ实际投递时间可能有差异。成功的群不重复发；
超时或发送中崩溃时，无法确定 QQ 是否收到，会记录告警并等待人工核实。
核实后可 `/发题 Q0001 重试`、`/答案 Q0001 重试`，只重试结果不明的群。
题库断档、图片损坏和同步失败均保留告警，管理员离线不丢告警。

## 批量导入

机器人私聊支持 `/导入题库 <JSON数组>`（图片用公共URL）。JSON/XLSX文件使用服务器 CLI：

```sh
python -m src.quiz.cli --actor 管理员姓名 import docs/questions-template.json
python -m src.quiz.cli list
python -m src.quiz.cli settings
python -m src.quiz.cli settings '{"groups":["123456"],"enabled":true}'
python -m src.quiz.cli export data/quiz/exports
```

从项目根目录运行，CLI 使用同一 `.env` 和 `DATA_DIR`。操作系统登录权限即 CLI 管理权限，不检查 QQ 身份。
模板为格式示例，须人工复核题目并调整实际日期后导入。XLSX读取第一张表，第一行表头：
`题干、A、B、C、D、正确答案、分值、解析、计划发布日期、图片、截止时间`。
可用2~6个连续选项列（A~F）；JSON也可用 `options` 数组。日期支持Excel日期单元格或YYYY-MM-DD。
图片可填公共URL或题库文件目录下相对路径，不接受目录外文件；XLSX内嵌图片请先导出成文件并填写相对路径。
每次1~366题，题库至多10MB，XLSX解压至多40MB。整批校验失败不新增任何题，已下载的图片可保留作缓存。

## 成员作答和成绩

成员私聊 `/答 A`、`/答 Q0001 A`；只有恰好一题可作答时才捕获裸字母 `A`（支持小写、全角）。
没有活动题目时正常聊天。多题时使用带题号命令。群里提交只提示改为私聊。
重复提交只保留首次答案；同一OneBot消息重推返回原回执，不重复记分。
提交回执不显示对错，个人总分、排行、导出和云同步均只纳入已结算题目。

`/排行` 看Top10，`/我的成绩` 仅私聊本人；管理员私聊 `/查分 QQ号` 查看逐题记录。
`/调分 Q0001 QQ号 0.5 申诉原因` 设置已结算单题得分；不写题号则增减总分。
原始答案与正确性保留，调分人、原因、分差和时间单独审计；正确率仍按原始答案计算。
`/导出` 发送汇总、明细与审计CSV。管理员导出含QQ号，须妥善保管。
登录端须能读取同机导出路径；容器需要挂载目录，并设置 `QUIZ_ONEBOT_EXPORT_ROOT` 为容器内导出目录。
自动撤回成员剧透、撤回已发题目尚未实现；发错请提前结算、说明情况并重新录题，不改原始记录。

## 腾讯文档与持久化

本地采用SQLite事务（WAL、FULL同步），将答题、计分、审计和待同步任务放进同一事务。
这替代需求草案的多JSON文件方案，避免并发或断电导致文件之间不一致。
停止服务后备份整个 `DATA_DIR/quiz/`；运行中备份使用SQLite backup接口，不要只复制主文件而漏掉WAL。
备份、迁移时应保留整个目录，包括图片和数据库。

云同步默认关闭。需要腾讯文档开放平台授权和两张**专用空白普通在线表格子表**，
配置 `.env.example` 中的 `QQDOC_*`；file ID应使用开放平台ID，不能直接假定分享链接末段是API ID。
每5分钟补传，也可 `/同步`。固定行号覆盖写入，失败保留版本任务；汇总列为昵称/总分/答对数/参与天数/最近提交时间，
明细列为题号/昵称/选项/正确性/得分/时间，不额外上传QQ字段。昵称若自行包含QQ仍会原样出现。
两张子表由程序管理，不要手工插入、排序或删除行；请在其他子表做展示与排序。
建议管理员编辑、成员只读；访问令牌需由管理员按开放平台要求更新。

腾讯文档适配器当前只有HTTP模拟契约测试，**尚未使用真实文档验证**；
账号、授权范围、ID、写入响应和权限仍需实际验收。参考[腾讯文档开放平台](https://docs.qq.com/open/document/app/openapi/v2)。
QQ登录和真实发图/私聊/成员验证/文件上传也须在账号就位后验收；模拟OneBot通过不代表真实QQ通过。

## 开发验证

`python -m pytest -q` 检查事务、并发、规则、权限、向导、图片归档和同步重试。
`python scripts/verify_onebot.py . onebot-probe.json` 启动临时数据目录和随机本机端口的真实机器人进程，
使用模拟OneBot验证录题到结算的消息链路，不连接QQ。CI在Windows/Linux、Python3.10/3.13运行两类检查。
可设置 `PROBE_MODEL=1` 额外调用本机 `127.0.0.1:11435` 的 `qwen3.5:9b`，需要事先准备独立模型运行环境。
