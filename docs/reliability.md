# 聊天与运行可靠性

基于 `643e161`（v1.3.3）。上游 `e7a995c` 已加入昨日发现的昵称 / @ 唤醒修复；本次沿用该实现，补上经过 OneBot 适配器预处理的回归测试，并处理短昵称抢先截断长昵称的情况。

已修复并验证：

- 模型服务连接失败后，每次新请求可重新连接；连接超时独立限制为 5 秒。
- 同一会话串行读取上下文、生成与写回；不同会话可并行。`/reset`、切换人设或模型会作废正在生成的旧回复。
- 敏感词检测与替换使用相同的归一化规则，替换原文中相应的完整区间。
- 群消息统计在事件预处理阶段执行，避免阻断型命令漏记；空闲时也会定时落盘。
- JSON 写盘失败会抛出异常，不能继续报告“保存成功”；临时文件在失败后清理。
- 异常钩子在运行中的事件循环上安装；启动异常使用非零退出码；插件加载不全时停止启动。
- `FAMILIAR_USERS` 可独立配置熟人互动对象，不授予管理权限；省略时保留原有行为。心事卡只显示请求者本人的 QQ。
- QQ 图片真实传入 Ollama 的 `images` 字段，每轮最多 3 张、每张不超过 8MB；会话 JSON 不保留图片 base64。模型须支持图像输入。模型生成的正文按纯文本发送，不能构造 CQ 操作。

可调配置见 `.env.example`：`AI_MAX_CONCURRENT`、`AI_CONTEXT_SIZE`、`AI_NUM_PREDICT`、`OLLAMA_THINK`。`DATA_DIR` 可指定数据目录，默认仍为项目下的 `data/`。

运行回归测试：

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

测试使用临时数据目录和模拟模型 / OneBot 消息，不登录真实 QQ，不向群或成员发送消息。CI 覆盖 Linux / Windows、Python 3.10 / 3.13；本地测试通过不等于远端 CI 或真实 QQ 验收通过。
