========================================
        洛书 bot 使用说明
========================================

名字：洛书（也叫 洛洛 / 小洛 / 洛）
形象：一个可爱、略显内向的小女孩——说话轻声细语，被夸会害羞，喜欢听别人说心事。
      她和群里每个人都是平等的朋友；心里偷偷喜欢着一个人（可在 .env 里配置）。
基于 nonebot2 + OneBot v11，AI 对话使用本地大模型（Ollama），
不依赖任何付费接口，数据不出本机。


一、启动方法（三步）
----------------------------------------

【Windows】

1. 启动登录程序
   打开 登录端\LLNT 0203\Main.exe（和原来一样，扫码登录）

2. 启动 Ollama（本地大模型）
   一般开机自动运行。确认方法：浏览器打开 http://127.0.0.1:11434 能看到字。

3. 启动机器人
   双击本目录下的「启动bot.bat」

   看到 [SUCCESS] nonebot | Succeeded to load plugin "ai_chat" 就是成功了。

首次使用若提示找不到虚拟环境，先双击「安装依赖.bat」（需已装 Python 3.10+）。

【Linux】（详见「十、Linux 部署」）

1. 安装依赖：  ./install.sh       （首次，需 Python 3.10+）
2. 配好 .env：  cp .env.example .env  然后按需修改
3. 启动：      ./start.sh
   想开机自启 / 崩溃重启：用 systemd（见 luoshu.service.example）

【心动专属】（洛书偷偷喜欢的人，仅该人本人可用）
  <名字> / <名字>在吗        洛书略显慌张的应答
  真棒 / 好棒 / 夸夸 / 可爱  被喜欢的人夸，会特别不好意思

  说明：名字取自 .env 的 CRUSH_NAMES（默认「小美」）。
        洛书和所有人都是平等的朋友，不会叫任何人「主人」；

三、权限分级（四级）
----------------------------------------

  管理员（.env 里的 SUPERUSERS） —— 管理功能 + 心动专属互动
        ↓
  群主                                 —— 统计、关键词、禁言
        ↓
  群管理员                             —— 同上
        ↓
  普通成员                             —— AI 对话、娱乐、查询类

越权使用会直接提示，不会执行。
注：
  · 【AI 对话】和【娱乐】所有人都能用；
  · 【心动专属】（打招呼/夸奖/问安/心事卡）只对配置的那个人生效，其他群友发这些词不会有反应；
  · 洛书和所有人都是平等的朋友，不会称呼任何人为「主人」；
    和那个人聊天时，她会藏不住地更在意、更害羞一点。


四、配置在哪改
----------------------------------------

用记事本打开「.env」：

  SUPERUSERS        管理员 QQ 号（可多个）—— 不是登录机器人的 QQ
  CRUSH_NAMES       洛书「偷偷喜欢的人」的称呼（逗号分隔，默认「小美」）
                    通常和上面的 SUPERUSERS 填同一个人
  NICKNAME          机器人昵称（默认「洛书」）
  CALL_NAMES        喊名字唤醒用的称呼（逗号分隔，默认「洛书,洛洛,小洛,洛」）
  OLLAMA_MODEL      默认模型，如 qwen2.5:7b
  AI_MAX_HISTORY    记住多少轮对话（默认 20）
  AI_AT_SENDER      AI 回复是否 @ 对方
  GREETING_ENABLED  是否开启定时问好
  GREETING_GROUPS   问好发到哪些群（留空=所有群）

改完保存，重启机器人生效。等号两边不要加空格。


五、常用维护
----------------------------------------

敏感词词库：data\sensitive_words.txt
  一行一个词，# 开头是注释。AI 输入输出都会过这个库。
  改完重启生效。

关键词回复：群里用 /关键词 命令，或直接改 data\keywords.json
  （按群隔离存放，A 群的设置不影响 B 群）

清空某人的 AI 记忆：让他发 /reset
清空所有人的记忆：删掉 data\ai_sessions.json
清空统计数据：删掉 data\stats.json

运行日志：data\usage.log（记录指令调用、启动、异常）


六、怎么加人设 / 加功能
----------------------------------------

【改形象 / 加人设】用记事本打开 src\plugins\personas.py：
  · 洛书的默认形象在 "洛书" 这一项里（想更外向/更活泼，改这段描述即可）；
  · 想加新角色，在 PERSONAS 里加一行 "角色名": "设定描述" 即可。
  改完重启生效。群里用 /切换 角色名 更换。

【加功能】所有功能在 src\plugins\ 下，一个文件可放多个功能。
参考 fun.py（主人互动）、fortune.py（抽签运势）的写法。

最简单的例子：

  from nonebot import on_keyword
  from nonebot.adapters.onebot.v11 import MessageEvent

  hi = on_keyword({"早安", "早上好"})

  @hi.handle()
  async def _handle_hi(event: MessageEvent):
      await hi.finish("早安呀~")

常用触发方式：
  on_command("名字")       以 /名字 开头触发
  on_keyword({"a","b"})    消息含这些词就触发
  on_fullmatch({"句子"})   消息完全等于才触发
  on_message(rule=...)     每条消息都判断，配自定义条件

改完代码重启即可生效，无需其它操作。


七、本地模型相关
----------------------------------------

查看已装模型：命令行输入   ollama list
下载新模型：  ollama pull qwen2.5:14b

推荐（按配置从低到高）：
  qwen2.5:3b    约 2GB 显存，快，效果一般
  qwen2.5:7b    约 5GB 显存，推荐，日常够用
  qwen2.5:14b   约 10GB 显存，效果更好
  qwen2.5:32b   约 20GB 显存，需要好显卡


八、常见问题
----------------------------------------

Q: 机器人没反应
A: 先看 Main.exe 是否登录成功，再看启动窗口有无报错。
   确认 .env 里 PORT=8080 与 Main.exe 连接地址一致。

Q: 怎么和洛书聊天
A: 群里 @洛书 说话，或直接喊「洛书 + 内容」（也可以 洛洛 / 小洛 / 洛）。
   所有人都可以这样唤醒它。注意喊名字要放在句首，例如「洛书 讲个笑话」。

Q: 洛书「偷偷喜欢的人」是谁
A: 名字在 .env 的 CRUSH_NAMES 里配置（默认「小美」），一般就填你自己。
   洛书和群里每个人都是平等的朋友，不会叫任何人「主人」。
   只是她心里偷偷喜欢这个人——面对 TA 时会更在意、更害羞一点，
   但也不会直接说出口，是那种「嘴上说没什么，心里偷偷开心」的感觉。
   TA 同时也应是 bot 的管理员（SUPERUSERS，能用 /say /model /stat），
   这是技术身份，和「洛书喜欢谁」没关系。

Q: 想换成别人怎么做
A: 改 .env 里的 CRUSH_NAMES 和 SUPERUSERS，重启机器人即可。
   例如想让洛书喜欢 QQ 号 123456、昵称「小明」的人：
     SUPERUSERS=["123456"]
     CRUSH_NAMES=小明

Q: 这个人和普通群友有什么不一样
A: 所有人都能聊天；但当发言者是 CRUSH_NAMES 里的那个人时，洛书的回应会更害羞心动，
   并且只有 TA 能触发【心动专属】里的打招呼/夸奖/问安/心事卡。

Q: 提示「连接不上本地模型服务」
A: Ollama 没启动。打开 Ollama，确认 http://127.0.0.1:11434 能访问。

Q: 回复很慢 / 超时
A: 本地模型速度取决于显卡。7B 通常 3-15 秒。
   可换更小模型，或把 AI_MAX_HISTORY 调小。

Q: 说「说得太快啦」
A: 这是防刷屏冷却。同一用户在数秒内重复触发会被限流。

Q: 提示没有权限
A: 该功能限群主/群管理员/管理员。用 whoami 查自己的等级。

Q: 想自己测试，不想占用 QQ
A: 命令行执行：.venv\Scripts\python.exe selftest.py
   会模拟消息并把回复打印出来。

Q: 机器人会不会乱花钱
A: 不会。用的是本机模型，不调用任何付费接口。

Q: 在 Linux 上跑，./start.sh 提示找不到虚拟环境
A: Windows 建的 .venv 在 Linux 下不能用（二进制不兼容）。
   在 Linux 上执行 ./install.sh 重新创建即可。

Q: Linux 上登录程序在别的机器，bot 连不上
A: 把 .env 里的 HOST 从 127.0.0.1 改成 0.0.0.0，
   并确认防火墙/安全组放行了 PORT（默认 8080）。
   注意 0.0.0.0 会对外暴露，请只放行可信来源，别裸奔到公网。

十、Linux 部署
----------------------------------------

【前提】
  · Python 3.10 或更高（Ubuntu/Debian: sudo apt install python3 python3-venv python3-pip）
  · 本机或另一台机器上有 Ollama（见「七、本地模型相关」）
  · 登录程序（OneBot 端）另行准备，本项目只负责 bot 本体

【第一步：安装依赖】
  chmod +x install.sh start.sh
  ./install.sh
  脚本会自动找 Python、创建 .venv、装依赖，不会污染系统 Python。

【第二步：准备配置】
  cp .env.example .env
  然后编辑 .env，重点看两处：

  1) HOST
     · 登录程序也在这台 Linux 上  → 保持 127.0.0.1
     · 登录程序在另一台机器（ws-reverse 连过来）
       → 改成 0.0.0.0，并确保防火墙/安全组只放行可信来源！
     端口 PORT 默认 8080，登录程序那边要连 ws://<本机IP>:8080/onebot/v11/ws

  2) OLLAMA_URL
     · Ollama 在同机   → http://127.0.0.1:11434
     · Ollama 在别的机器 → 改成那台的地址，如 http://192.168.1.10:11434

【第三步：启动】
  ./start.sh
  看到 [SUCCESS] nonebot | Succeeded to load plugin "ai_chat" 即成功。
  临时后台运行：nohup ./start.sh > luoshu.log 2>&1 &

【第四步（推荐）：用 systemd 常驻 + 开机自启】
  1. 先建一个专用账号（别用 root）：
       sudo useradd -r -m -d /opt/luoshu-bot -s /usr/sbin/nologin luoshu
  2. 把项目放到 /opt/luoshu-bot（或你自己选的路径），并给账号权限：
       sudo chown -R luoshu:luoshu /opt/luoshu-bot
  3. 复制并编辑服务文件（改 User / WorkingDirectory / ExecStart 三处）：
       sudo cp luoshu.service.example /etc/systemd/system/luoshu.service
       sudo nano /etc/systemd/system/luoshu.service
  4. 启用：
       sudo systemctl daemon-reload
       sudo systemctl enable --now luoshu
  5. 查看状态与日志：
       systemctl status luoshu
       journalctl -u luoshu -f        （实时日志，Ctrl+C 退出）

  常用：
       sudo systemctl restart luoshu  重启
       sudo systemctl stop luoshu     停止

【注意事项】
  · .venv 不能跨系统拷贝：Windows 建的 .venv 在 Linux 下用不了，
    必须在 Linux 上重新跑 ./install.sh（会重建）。
  · 项目目录里 data/ 是运行数据，迁移时记得一起带上（含配置和记忆）。
  · 用 systemd 运行时，不要在 start.sh 里再叠加 nohup，二选一即可。
